## 🚀 Key Featured Works

### 1. End-to-End Centralized Server Management Platform
- **Live Access**: [server.jsisoftwaresolutions.in:10000](https://server.jsisoftwaresolutions.in:10000/)
- **Summary**: Designed and deployed a unified server control environment for JSI Software Solutions — bringing server operations, web hosting, domain DNS, database administration, and security controls into a single administration system.
- **Key Features**:
  - Unified administration layer for web hosting, domains, and DNS routing.
  - Centralized MySQL / MariaDB database management.
  - Granular access control and service exposure reduction.
  - Scalable multi-tenant infrastructure architecture.

### 2. Custom Email Server & Mail Infrastructure
- **Live Access**: [email.jsisoftwaresolutions.in](https://email.jsisoftwaresolutions.in/)
- **Summary**: Constructed a complete, self-hosted email infrastructure from scratch for JSI Software Solutions, replacing third-party dependencies with an internal delivery backend and Roundcube webmail interface.
- **Key Features**:
  - Full mail delivery stack: SMTP, DNS, SPF, DKIM, and DMARC alignment.
  - Sender IP reputation management & deliverability optimization.
  - Roundcube webmail client integration.

### 3. Secure Shutdown — Android Security & Anti-Theft App
- **Live App**: [Google Play Store Listing](https://play.google.com/store/apps/details?id=com.secure.shutdown.dj) \| [Official Website](https://secure-shutdown.jsisoftwaresolutions.com/)
- **Summary**: Android security application engineered to protect mobile devices from unauthorized power-off attempts, restarts, and stolen device lockouts.
- **Key Features**:
  - Unauthorized power-off and restart blocking.
  - Intruder photo alerts with real-time Telegram API notifications.
  - Anti-theft lockdown controls and suspicious activity detection.

### 4. Cyber Baithak — Free Cyber Security Awareness Program
- **Official Site**: [cyberbaithak.com](https://cyberbaithak.com/)
- **Summary**: Free public cyber safety awareness initiative under JSI Software Solutions aimed at empowering Indian citizens against digital fraud.
- **Key Features**:
  - Hands-on workshops covering phishing, AI fraud, password security, UPI/banking safety, and mobile security.
  - Partnered with educational institutions and law enforcement cells.
  - 100% free registration and verified completion certificates for all participants.
